# Features

## Player submit strip

Flag / Submit timestamps opens a landscape bottom sheet on the video.

- One segmented control: Intro, Recap, Credits, Preview. Movies show Intro and Credits.
- One chip for the open tab: No intro, No recap, No credits, or No preview. One tap marks that segment as none, hides the timeline and nudges, and Submit reads "No intro · S1 E22" (or the movie equivalent). The submit sends 0 and 0 plus the stream length. Tapping the open tab returns to editing.
- A live status shows the length and the allowed range, or the error. An end equal to the video length stays valid.
- The timeline has start and end handles and a play-range control on the marked range.
- Start and End choose which side the nudge buttons change. Set to now writes the playhead onto that side.
- Nudges are −5, −1, +1, and +5 seconds. Holding a button steps by 0.1 s. Clocks show whole seconds until a 0.1 step.
- Submit sits on the right.
- The overflow menu has Copy link, Play range, and Reset marks.
